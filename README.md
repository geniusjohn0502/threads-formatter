# 🧵 脆排版器

把草稿貼進來 → 直接改 → 一鍵複製貼到脆（Threads），段落間距不會被吃掉。

**網址：https://geniusjohn0502.github.io/threads-formatter/**

由 [灰哥](https://www.threads.com/@more__choice) 製作，免費使用。

---

## 它解決什麼問題

| 問題 | 做法 |
| :--- | :--- |
| 貼到脆之後，段落之間的空白行被吃掉 | 複製時在每個空白行塞一個看不見的字元（U+2800 點字空白），脆不會把它清掉 |
| 超過 500 字貼上去，脆會自動切段並把換行壓成一整片 | 超過 500 字時出現「自動分段」按鈕，先在這裡切好，每篇都在上限內 |
| 預覽的斷行位置跟手機上看到的不一樣 | 預覽的一行字數可以用「換行寬度」滑桿調到跟自己手機一樣，調過會記住 |

## 怎麼用

1. 把草稿貼到左邊的「串文 1」，直接在上面改。
2. 超過 500 字 → 字數變紅、出現「自動分段」，按一下就會照段落切成好幾篇。
3. 每一篇各自按「複製」，依序貼到脆。貼 Facebook 則用上方的「複製全文」。
4. 右邊預覽的斷行跟手機對不起來時，拖動預覽區上方的「換行寬度」滑桿，
   拖到預覽的換行位置跟自己手機上看到的一樣為止（不必真的去數字數）。

## 你的內容存在哪裡

**只存在你自己的瀏覽器裡**（`localStorage`），不會上傳到任何地方，作者也看不到。

- 不小心關掉再打開，草稿還在
- 清除瀏覽器資料、用無痕模式、換手機或換電腦 → 草稿會不見，**長文請另外備份**
- 公用電腦用完請按「清空全部」

這是一個純前端的單一 HTML 檔，沒有後端、沒有資料庫、不呼叫任何 API，也沒有訪客統計。

## 運作原理（要改程式再看）

整個工具就是 `index.html` 一個檔案，沒有任何相依套件。改完推上 `main` 分支，GitHub Pages 約 1 分鐘後生效。

### 1. 保留空白行

複製時把「整行只有空白」的行換成 `⠀`（U+2800，點字空白）。脆會保留這個字元，所以段落間距不會被壓掉。

字數計算的是**實際複製出去的字數**，因此這些隱形字元也算進 500 字，避免畫面顯示沒超過、貼上去卻超過。

### 2. 自動分段

脆在手機上貼入超過 500 字時，會自動切成多篇串文（[官方公告](https://www.threads.com/@threads/post/DYCkTAQAKOl/this-ones-for-you-writers-of-threads-on-mobile-when-you-paste-a-block-of-text/?hl=en)），使用者回報此時換行會被壓掉。
所以改成在這裡先切好，切的優先順序是：

```
段落（空白行）→ 換行 → 句子（。！？；）→ 硬切
```

每一份都用「實際複製出去的字數」判斷是否 ≤ 500。

### 3. 預覽的換行模擬

預覽欄比脆窄（390px 寬的手機上，預覽約 249px、脆約 314px），一行放的字較少，斷行位置就會不同。
而每個人的手機寬度、系統文字大小、顯示縮放都不一樣，一行放得下幾個字差很多，猜不準——
所以不猜，直接讓使用者用滑桿指定「一行幾個字」（`cpl`，範圍 10–26，整數）。

中文字的寬度約等於字級，所以：

```
每行的可用格數 slots = cpl + CPL_SLACK
預覽文字欄寬度 w = min(實際可用寬度, slots × MAX_FONT)
預覽字級 = w / slots
```

`CPL_SLACK = 0.3` 是每行多留的一點餘裕：手機上的數字、英文、標點比瀏覽器裡窄一些，
留這點空間斷行才對得上。不到 1 個字，所以純中文的一行仍然剛好是設定的字數
（10–26 每一格都驗證過）。`MAX_FONT = 17` 是桌機上的字級上限，避免字被放到太大。

> ⚠️ **`0.3` 是用兩張使用者的實際截圖反推的，不是官方數據。**
> 最早只用一張截圖調出 `0.8`，第二張截圖一驗就掉到 6/11 —— 單一樣本會調出假的精準。
> 目前兩個樣本分別是 10/12 與 9/11 行吻合。
>
> ⚠️ 實測發現**同一支手機、同一則貼文，含英文的段落與純中文段落的斷行寬度並不一致**，
> 所以沒有任何單一設定能 100% 吻合。這是模擬，不是還原。

### 4. 改動時請一起確認

- 三個地方共用同一套字數計算：字數顯示、紅字、自動分段按鈕的出現時機
- 已存在的使用者草稿存在 `localStorage` 的 `threads_formatter_v2`，改資料格式時要考慮舊資料
